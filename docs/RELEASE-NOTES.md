# v1.1.1 更新说明（2026-09-09）

> 本版本针对 v1.1.0 实测反馈的全面修复版。因构建环境重置导致源码丢失，本版本为**依据完整技术记录与协议证据重建**的工程（结构与 v1.1.0 对齐），并修复以下问题。

## 修复清单（对应 v1.1.0 反馈）

### 1. 会话列表抖动
- 所有列表项**固定行高**（56px），头像/文本不随内容改变布局
- 未读角标与 [@我] 标签改为**绝对定位**，出现/消失不再挤动行内元素
- 会话排序引入**稳定二级键**（时间相同时按 ID），同秒刷新不再跳动
- 状态横幅固定高度，仅在连接状态变化时刷新
- 列表仅在消息/列表事件时重建，避免高频重渲染

### 2. 输入法字库仍为 8 千多字
- 字库从 8241 字扩展至 **14718 字**（pinyin-data 全量，覆盖 CJK 基本区所有有读音汉字）
- 417 个音节，多音字全部支持（的得地等都正确归组）
- 候选排序按 **GB2312 一级字表（3755 常用字）优先**，高频字排前面（如 de → 的、得）
- 数据体积 163KB（rpk 总体积仍在 180KB 内）

### 3. 无法加载历史信息
- 远端翻页锚点修复：优先使用 OneBot 历史响应中的 **message_seq**（history_seq），回退 message_id（v1.1.0 用 message_id 当 message_seq，对 NapCat 等实现锚点错位导致查询为空）
- 时间过滤统一**毫秒**（此前秒/毫秒混用导致锚点过滤为空）
- 本地缓存翻页兜底 + 6 秒超时提示（「加载失败，点按重试」）
- 防并发：同一会话翻页请求去重

### 4. 冷启动看不到别人发的消息
- **连接回放机制**：手环通道接入后，同步器自动把缓存的最近 24 小时消息（每会话最多 10 条、总量 50 条）按时间序推给手环
- 手环端按 message_id **幂等去重**：已看过的消息不重复计未读、不重复震动
- 手机端收到消息**无论手环是否在线都持久化**，保证回放数据完整
- 手环端 ensureAlive 自愈增强：通道失效自动重建并重拉全量状态

### 5. APK 有图标但快应用没有
- manifest.json 增加顶层 `"icon": "/common/icon.png"` 字段（Vela 规范）
- 192×192 图标已打进 rpk 包内 common/ 目录（已验证）

### 6. 自发消息 sender 记录错误（隐藏 bug）
- 修复：自己发的消息 sender_id/sender_name 不再错误填成「会话 ID/会话名」，改用登录账号信息
- **self-echo 合并**：服务器推回自己消息时并入乐观回显条目（同内容 5 秒内），不再重复显示
- 旧脏数据由 schema v2 清理（升级后首次启动自动执行）

### 7. 其他加固
- 消息持久化**串行写队列 + 防抖**：快速连续消息不再竞态丢数据
- OneBot WS 请求 8 秒无响应自动转 HTTP 重试
- 手环端 WebSocket API **多形状适配**（兼容不同 Vela 版本的 websocketfactory 接口差异）

## 升级说明
- 直接安装新 APK 与新 rpk 覆盖旧版即可
- 首次启动手环应用会自动执行旧数据清理（schema v2）

## 测试
- 手环端：`node --test` 14 例全通过
- 手机端：`gradlew testDebugUnitTest` 13 例全通过（协议解析 8 例 + 翻页/回放 5 例）
